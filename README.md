# 수학 실험실 · Math Lab

수열과 급수, 테일러와 푸리에, 리만합과 적분, 함수 근사를 움직이는 그래프로 탐구하는 수업용 웹사이트.

**사이트:** https://huhjeonggyu.github.io/math-lab/

## 실험실

- **수열과 급수** (`docs/labs/sequences/`): 8개 예제에서 항 `a_n`과 부분합 `S_n`을 나란히 비교합니다. 재생, 한 항씩 진행, 관찰 범위, ε 수렴 띠를 지원합니다.
- **테일러와 푸리에** (`docs/labs/taylor/`): 6개 급수의 부분합과 비교 함수를 함께 그리고, 수렴 구간과 선택한 점의 오차를 확인합니다.

- **리만합과 적분** (`docs/labs/riemann/`): 8개 예제의 직사각형 합을 재생합니다. 왼쪽·가운데·오른쪽 표본점, 부호 있는 넓이, 분할 오차와 이상적분의 수렴·발산을 비교합니다.
- **테일러 다음의 함수 근사** (`docs/labs/approximation/`): 1학년 심화 학습용 페이지입니다. 4개 함수에서 테일러, 최소제곱 다항식, 체비쇼프 보간, 자연 3차 스플라인, 푸리에를 비교합니다. 차수 재생, 중심 이동, 보간점 표시, 오차 그래프와 수치 비교를 지원합니다.

HTML, CSS, JavaScript ES modules, Canvas, MathML만 사용합니다. 실행에 외부 라이브러리, 계정, API 키가 필요하지 않습니다. 계산은 방문자의 브라우저에서 수행합니다.

## 로컬 실행

```sh
python -m http.server 8000 --directory docs
```

브라우저에서 http://localhost:8000 을 엽니다. ES module 때문에 HTML을 직접 더블클릭하지 말고 HTTP 서버로 실행합니다.

## 수학적 표현

- 그래프는 실제 정수 항 개수의 부분합을 표시합니다. 수렴 판정은 유한한 그림만으로 주장하지 않고 설명을 함께 제공합니다.
- ε 띠의 기준 인덱스는 충분조건이며 가장 작은 값이라고 주장하지 않습니다.
- 교대조화급수는 조건수렴이고, `1 − 1 + 1 − 1 + …`은 보통의 부분합 정의에서 발산합니다.
- 숫자는 반올림하여 표시합니다. 운영체제의 움직임 줄이기 설정을 따릅니다.

## 리만합과 이상적분

리만합은 각 조각의 실제 폭과 선택한 표본값의 곱을 더합니다. 비균일 분할의 가운데 표본점도 각 조각의 산술 중점입니다. 음수 영역은 음의 넓이로 합산합니다.

이상적분 예제에서는 분할을 촘촘히 하는 과정과 끝점을 이동하는 과정을 분리합니다. 먼저 고정된 `[ε, 1]` 또는 `[1, R]`에서 리만합의 오차를 줄이고, 그다음 정확한 적분의 `ε → 0` 또는 `R → ∞` 극한을 설명합니다. 끝점 이동 재생은 N을 고정하므로 정확한 적분 곡선과 리만합의 차이가 계속 표시됩니다. 발산 사례는 이상적분이며, 유한 닫힌 구간의 연속함수 리만합이 발산한다고 주장하지 않습니다.

## 함수 근사 비교

모든 함수는 `[-1,1]`에서 비교합니다. 다항식 차수 n, 스플라인 구간 수 n, 푸리에 최고 주파수 n/2로 맞추어 각각 n+1개의 자유 계수를 갖습니다. 단, 필요한 함수값과 도함수 정보의 양은 다르므로 같은 데이터 예산의 비교가 아닙니다.

- 최소제곱: 257개 등간격 점의 비가중 제곱오차 합을 최소화합니다. 체비쇼프 기저와 재직교화 QR을 사용합니다.
- 체비쇼프: n+1개 체비쇼프 근에서 보간합니다. Minimax 해라고 부르지 않습니다.
- 스플라인: 등간격 보간점과 양끝 2차 도함수 0을 사용하는 자연 3차 스플라인입니다.
- 푸리에: 주기 2의 실수 기저에 대한 연속 투영 계수를 2,048개 소구간 Simpson 적분으로 계산합니다.
- 오차 지표: 1,601개 평가 격자의 RMSE 및 최대 오차이며 연속 구간의 정확한 최댓값이라고 주장하지 않습니다. 로그 그래프는 10^-12 아래를 바닥에 표시합니다.

수학 테스트는 다항식 재현, 최소제곱 잔차 직교성, 보간점 통과, 스플라인 C2/자연 경계조건, 해석적인 푸리에 계수, 이동한 중심의 테일러 전개를 확인합니다.
